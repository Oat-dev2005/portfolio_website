## 📖 Overview (รายละเอียดเว็บไซต์)

This project is my personal portfolio website designed to introduce myself as a Computer Science student and aspiring Software Developer.
The website showcases my technical skills, featured projects, certificates, and contact information in a clean, responsive, and user-friendly interface.

It also serves as an online resume to showcase my projects and experience.

Portfolio Website เป็นเว็บไซต์ส่วนตัวที่จัดทำขึ้นเพื่อรวบรวมข้อมูลเกี่ยวกับตัวผู้พัฒนา ทั้งในด้านทักษะการเขียนโปรแกรม ผลงานที่ผ่านมา ใบประกาศนียบัตร และช่องทางการติดต่อ

เว็บไซต์นี้ถูกออกแบบให้เป็นเหมือน Resume ออนไลน์ เพื่อแสดงโปรเจกต์และประสบการณ์ที่ผ่านมาของตัวผู้พัฒนา
